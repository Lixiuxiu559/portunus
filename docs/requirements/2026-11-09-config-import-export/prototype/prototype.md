# 配置导入导出原型清单

状态：用户已审核通过。本文记录原型阶段的设计与走查；工程边界以已审核的 [Spec](../spec.html) 为准，当前实现见 [实施记录](../implementation-report.md)。需求依据：[PRD](../prd.html)，核心决策 D-01～D-08。原型只模拟交互，不调用服务、不读取业务配置、不实际加密或保存文件。

## 1. 投入与页面结构

采用 **T2 局部原型**：保留设置页骨架、顶部导航及已有设置卡片，只新增“配置迁移”区域和相关弹窗。入口放在“上游模型同步”之后、“服务接入”之前，是本轮布局建议，对应 PRD O-01；不增加主导航或生产路由。

入口：[index.html](index.html)。演示栏独立于业务界面，标明模拟限制、示例密码和状态切换。正常态默认为设置页。所有示例都是模拟数据。

| 编号 | 页面／区域 | 主要内容 | 需求依据 | 查看方式 |
|---|---|---|---|---|
| P-01 | 设置页中的配置迁移卡片 | 导出与导入入口，范围说明，源端三类计数 | D-01～D-03、FR-10 | 默认首页；`?scene=settings` |
| P-02 | 导出弹窗 | 全量范围、文件密码、确认密码、数量、导出中与完成结果 | D-01、D-02、FR-01、02、11 | 点击“导出配置”；`?scene=export` |
| P-03 | 选择文件与解密 | 文件选择区、文件名称、导入密码、校验中 | D-02、D-06、FR-02～04 | 点击“导入配置”；`?scene=import` |

## 3. 模拟数据与显示字段

示例迁移文件含 **3个渠道、8个模型、3个分组**。本机初始为2个渠道、4个模型、2个分组，含同名渠道 OpenAI／Anthropic 及同名分组 coding／daily。首次导入发生4项改名，新增后本机计数为5／12／5。本机主动导出时展示本机当时的实际模拟计数，而非始终使用示例文件的3／8／3。

来源应用版本示例为 v0.5.3，当前应用 v0.5.4（当前值来自 `web/package.json`，来源版本是模拟值）；二者文件格式均为1，明确演示“应用版本不同仍可导入”。不展示真实URL、凭据或用户数据。

| 字段 | 呈现与空值／超长规则 | 来源 |
|---|---|---|
| 三类计数 | 非负整数，分开显示渠道／模型／分组，不把三者相加为模型总数 | D-01、D-08 |
| 文件名 | 显示完整名称，可换行；例 `portunus-config-2026-11-09.portunus`；扩展名和默认名是建议 | O-01 |
| 来源应用版本 | 展示“导出应用 v0.5.3”；不可据此拒绝当前 v0.5.4 | FR-03、AC-07 |
| 文件格式版本 | 显示“文件格式 1”；正常预览同时显示受支持 | D-05 |
| 改名清单 | 对象类型、原名称、新名称；列出全部改名项，没有冲突时显示无需改名 | FR-06、FR-07 |
| 渠道详情 | 新增后的名称、原名称（改名时）、模型数量、保留连接配置状态；不显示凭据值 | FR-01、02、05 |
| 模型详情 | 模型原名、所属导入渠道；同名模型不能合并 | FR-05、06 |
| 分组详情 | 新增后的名称、手动指定／故障转移、当前模型／按顺序排列的成员及所属渠道 | FR-05 |

## 4. 表单与操作

| 项目 | 控件／默认值 | 校验与可操作条件 | 反馈及去向 |
|---|---|---|---|
| 导出文件密码 | password，默认空，可切换可见 | 必填；不擅自增加密码最短长度 | 空值显示就地错误 |
| 确认密码 | password，默认空 | 必填且与密码一致；这是本轮防误输入建议，对应 O-04 | 不一致时保留输入并提示 |
| 选择导入文件 | 点击选择区／“更换文件” | 原型直接载入示例文件，模拟系统选择动作；不读取实际文件 | 显示已选文件；清除／更换后旧预览失效 |
| 导入密码 | password，默认空，可切换可见 | 必填；模拟正确密码为 `demo1234`，仅在独立演示栏说明 | 校验失败保留文件，允许重输 |
| 选择位置并导出 | 导出弹窗右下主按钮 | 表单通过后显示进行中，禁止重复发起 | 模拟选择位置和保存，随后显示完成；无真实文件生成 |
| 解密并预览 | 选文件弹窗右下主按钮 | 已选文件且密码非空；处理时禁用 | 正常进入预览；异常显示原因和恢复入口 |
| 确认导入 | 预览右下主按钮，附三类新增数量 | 仅有效预览可用；处理中禁用 | 全部成功或整次回滚 |
| 返回／取消／关闭 | footer、右上关闭、Esc | 非处理中可用；关闭不改变模拟目标计数；处理中不允许关闭 | 返回设置或上一流程步骤 |
| 预览详情切换 | 渠道／模型／分组三个本地tab | 仅切换呈现，不变更导入范围 | 可查看完整模拟内容 |
| 查看分组 | 导入成功footer | 成功后可用 | 进入只读模拟分组列表，显示最终名称和关联；不代表生产路由 |
| 现有设置与导航 | 保留原外观与有限上下文 | 原型未制作的模块和既有写操作明确为只读占位，点击会说明；不假装连接生产能力 | 本地提示“本原型仅演示配置迁移” |
| 深浅色切换 | 顶栏主题按钮 | 没有弹窗时可用；弹窗继承主题；也可用 `?theme=dark` 直接查看 | 切换本地主题，不保存到应用 |

原型对新增配置的变更只保存在当前页面内存，刷新／“重置演示”恢复模拟初始值。连续再次导入会产生新的名称，例如“（导入 2）”，只是本轮命名建议，不改变自动新增的核心规则。

## 5. 状态与恢复路径

| 场景值 | 状态 | 展示／操作／恢复 | 关联 |
|---|---|---|---|
| settings | 正常设置入口 | 新增配置迁移区域；导入、导出可用 | P-01 |
| export | 导出表单 | 两次密码输入、全量说明、计数 | P-02 |
| exporting | 导出中 | 正在加密并导出，操作禁用；完成后结果页 | FR-11 |
| exported | 导出完成 | 文件名和数量，关闭返回设置 | FR-11 |
| export-error | 导出保存失败 | 不提示成功，返回导出可重试 | FR-11 |
| import | 未选文件 | 选择区、密码输入；未选文件不能预览 | P-03 |
| decrypting | 解密／校验中 | 保持选中文件，操作禁用 | FR-04 |
| preview | 正常导入预览 | 数量、格式、改名、全部详情；确认／返回 | P-04 |
| no-conflict | 无同名预览 | 无需改名，仍按全量新增 | FR-06 |
| importing | 导入中 | 保留预览上下文，操作禁用，完成后结果 | FR-08 |
| success | 导入完成 | 实际新增量及最终名称；查看分组或完成 | P-05 |
| wrong-password | 密码错误 | 不出现有效预览；重新输入密码 | FR-02 |
| corrupt | 文件损坏 | 不继续写入；更换文件 | FR-04 |
| version | 格式不一致 | 文件格式2／本应用支持1；无确认导入；更换文件 | FR-03 |
| invalid | 配置校验失败 | 显示示例分组成员引用缺失；整次不写入 | FR-04、05 |
| changed | 预览后名称变化 | 明确需重新确认，显示更新后的完整改名结果 | FR-07 |
| rollback | 导入失败，已全部回滚 | 三类新增均为0，原有数据保留；回到预览重试 | FR-08 |
| long | 超长名称／文件名 | 文件与名称换行、表格自身滚动、footer可见 | 可读性 |
| empty | 源端空计数 | 显示零计数和无内容；演示中暂禁用导出，外部演示栏标明该行为待确认 | O-03，非已确认业务规则 |
| groups | 导入后分组上下文 | 显示本次新增组、策略及成员，与导入结果对应 | AC-02、03、10 |

无筛选／搜索，所以筛选无结果不适用；没有用户角色分级或新增授权，因此不虚构“管理员／普通用户”及权限码。读配置失败在范围内以导出失败／导入校验失败表达；不添加新的应用全局权限机制。

## 6. 本轮设计建议与开放问题

- 建议入口放设置页“配置迁移”，两个独立操作行；避免增加主导航。
- 建议导出两次输入密码；不设未经确认的密码强度门槛。
- 建议 `.portunus` 作为文件扩展名；改名示例用“（导入）”“（导入 2）”。两者都不是已确认外部契约。
- 预览用三类详情tab减少纵向堆叠，但不能勾选排除内容，维持全量导入。
- 空库导出策略、密码强度与文件／数量限制仍按 PRD O-03、O-04 保留为开放项，不回写 PRD。
- 没有修改 PRD 正本；原型里的建议若采纳，应在后续需求更新时同步。

对照性质：使用当前源码值逐项核对，并以历史截图校准顶栏与卡片的视觉语言；**没有与运行中的当前设置页做像素对照**。现有应用没有启动，正式与Dev数据未读写。

已说明的视觉差异：未复现品牌扫光、液态导航动画和原主题开关九段动画；主题开关用同风格静态SVG表达。玻璃材质省略噪声纹理与部分分层高光，卡片24px圆角依据历史截图估计。新增预览表格及窄屏顶栏换行为设计建议，不把这些差异当作当前产品规范。

模拟限制：不访问真实后端，不操作安装版／Dev 数据，不读本机凭据，不发起上游请求，不实现密码学，不保存文件，也不模拟真实系统文件选择器的视觉。演示栏中的状态是设计走查入口，不能作为生产能力验收结果。

本地资源：`assets/project-theme.css` 为从项目现有主题提取的自包含样式；`assets/fonts/` 和 `assets/logo.png` 从仓库复制。业务原型源为 `index.html`、`prototype.css`、`prototype.js`，不依赖 PRD 文档母版或构建框架。
