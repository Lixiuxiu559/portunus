# 配置导入与导出

在“设置 → 配置迁移”中，将一台电脑上的渠道、模型和分组迁移到另一台电脑。

## 导出

1. 点击“导出配置”，输入文件密码并再次确认。
2. 选择保存位置，生成 `.portunus` 加密文件。
3. 将文件与密码交给目标电脑上的使用者。文件包含完整上游凭据，请妥善保管。

导出包含全部渠道的连接配置及凭据、全部已保存模型，以及分组策略、成员、当前激活项和备用顺序。没有配置时不能导出。导出不改变源端配置。

## 导入

1. 在目标电脑点击“导入配置”，选择文件并输入导出时的密码。
2. 查看来源应用版本、三类数量、全部改名结果和配置详情。
3. 确认后导入；成功结果可跳转查看本次新增分组。

导入全部作为新增对象，保留目标端现有配置。同名渠道或分组会使用“（导入）”“（导入 2）”等后缀；上游模型名不变。再次主动导入相同文件会新增另一套副本。若预览后的名称被其他操作占用，需要核对更新后的预览，再次确认。

导入离线检查文件、字段和关联，不主动请求上游。保存的自动同步设置仍会影响之后的正常后台调度。配置恢复完成不表示已经测试了上游连通性。

## 失败与恢复

- 密码错误、文件损坏、格式或能力不支持时不能进入有效预览，不会写入三类配置。
- 任何业务写入失败都会整次回滚。同一次确认重复提交只返回原操作结果。
- 提交后连接中断时显示“结果待核实”。继续查询原操作即可；应用重启后也能核实未确认的结果，避免误操作产生副本。
- 只有明确成功或失败时才显示终态。关闭结果后标记为已查看，不会删除防重复提交的记录。

## 格式与范围

首版仅支持文件格式 **1**，文件格式必须相同；来源应用版本可以不同。不支持选择性迁移、明文文件、覆盖已有配置、跨格式转换或云同步。

不会迁移 Portunus 服务接入 Key、监听端口、全局设置、客户端文件、日志、历史计价、独立余额查询来源或运行缓存。客户端使用目标电脑的接入地址、服务 Key 和最终分组名称。

受理上限同时生效：明文 32 MiB、文件 32 MiB + 64 字节；最多 1,000 个渠道、50,000 个模型、5,000 个分组、100,000 个成员；预览 8 MiB、结果 12 MiB。密码为 1～1,024 个 UTF-8 字节，空格和字符原样保留。超过任一上限会整体拒绝，不会截断导出或部分导入。

预览保留 15 分钟，过期后需要重新校验。此功能不能绕过或恢复遗失的文件密码。

需求、原型及技术契约见 [配置迁移需求目录](requirements/2026-11-09-config-import-export/spec.html)。
