# Portunus v0.5.0

本版本完善多工具接入、上游渠道管理、调用诊断与桌面交互，并优化前端加载和大列表操作。

## 多工具 API Key

- 支持创建多把命名 API Key，可分别用于 Claude Code、Codex 等工具。
- 支持重命名、重置、可恢复禁用与删除；删除后从管理列表隐藏，历史调用和用量保留。
- 调用记录保留调用时的 Key 名称，用量和筛选按稳定 ID 区分。旧日志未采集名称时明确标为未记录。

## 渠道与模型分组

- 渠道添加和编辑采用分块布局，支持厂商预设、接口协议、内置品牌图标与自定义图片。
- 模型发现与导入选择分开，支持手动添加模型、大量候选分页与跨页选择；保存只导入选中项。
- 支持独立的余额/额度来源、缓存展示、主动查询及可配置自动刷新。
- 完善分组多成员创建、模型搜索、手动选择、故障转移和备用顺序管理。
- 修复低窗口高度下无法操作保存/取消、Key 显示导致列宽跳动，以及刷新后余额摘要样式缺失的问题。

## 调用观测与网关

- 日志支持按 API Key、渠道、分组、模型等条件查询，提供请求关联、上游尝试链与路由诊断详情。
- 保留 Token 与缓存用量统计；日志行和上游尝试分别记录，不将其混为准确客户端请求数。
- 完善 OpenAI Chat、Responses、Anthropic 与 Gemini 之间的协议转换，以及工具调用、流式结束和预算截断等边界。
- 完善渠道并发、限流、熔断探测、超时、重试和故障转移控制。

## 界面与性能

- 接入指南采用树形导航，统一连接配置、请求示例与 Claude Code 配置编辑入口。
- 页面和低频编辑器按需加载，增加局部加载失败恢复入口。
- 首屏实际加载 JS 在本地验收场景中减少约 41%；分组搜索输入不再重建全部拖拽成员。
- 日志长内容可悬浮查看；移除相互干扰的表格外阴影。
- 增加可运行的前端类型检查并纳入 CI。

## 升级说明

- 沿用现有本地数据与配置；旧单 Key 保留原密钥和 ID，并迁移为默认 Key。
- Dev 使用独立应用身份、端口和数据目录，避免开发调试影响正式配置。
- 管理接口只允许本机回环访问；服务接口继续使用 API Key 鉴权。
- 不提供调用费用计算；实际模型生成和主动余额查询仍遵循上游服务规则。
- 当前安装包未配置 Developer ID/Windows 签名，macOS 自动更新仍有签名限制；安装方式见仓库 README。

安装包：macOS Apple Silicon（DMG/ZIP）、Windows x64（安装程序/ZIP）、Linux x64（AppImage）。
