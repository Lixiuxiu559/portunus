# 装饰动画 CPU 对照验证

日期：2026-10-27。基线：`faac23d`，优化在 `dev` 工作区。原始数据见 [measurements.json](measurements.json)。

## 修改

- 四块背景色块保留原来的位置、尺寸、颜色、64px 模糊和深色压暗配方，取消无限漂浮及常驻 `will-change: transform`。
- 标题扫光从每 4 秒无限循环改为悬停播放一次，持续 1.4 秒。系统选择减弱动态效果时，悬停也不播放。
- 保留现有玻璃、透明度、阴影、主题切换和导航交互样式；未禁用硬件加速。

## 实测方法

本机 macOS 27.0.1（26A434）、arm64、Electron 42.3.3。优化前后分别执行 `cd web && pnpm run build:dev`，运行同一路径的独立 Portunus Dev 目录包，使用同一 Dev 数据和渠道页面（2 张卡片），窗口内容尺寸均为 1280×720。正式版保持原样。

通过仅本机 CDP 端口连接实际 Electron 进程，以 `SystemInfo.getProcessInfo` 的累计 `cpuTime` 差除以墙钟时间计算进程 CPU，100% 表示占满一个逻辑核心；GPU 进程的 CPU 不代表硬件 GPU 利用率。

浅色、深色分别稳定等待 7 秒，截图后再等待 3 秒，各连续采样两段约 20 秒，按实际时长加权平均。采样前后检查 `document.visibilityState === 'visible'`，两版本均为可见但未获焦点的窗口，不以最小化状态代替静置基线。未主动刷新余额或发起模型调用。采样包含应用正常缓存轮询及系统调度噪声。

## 结果

| 主题 | 进程 | 优化前平均 CPU | 优化后平均 CPU |
| --- | --- | ---: | ---: |
| 浅色 | GPU Helper | 40.27% | 0.06% |
| 浅色 | Renderer | 12.08% | 0.18% |
| 深色 | GPU Helper | 44.20% | 0.04% |
| 深色 | Renderer | 13.07% | 0.04% |
| 浅色 | 主进程 | 0.09% | 0.32% |
| 深色 | 主进程 | 0.02% | 0.06% |

本轮静置条件下，GPU 与 Renderer 合计 CPU 下降超过 99%。主进程未呈现相同方向的下降，不将全部进程都描述为性能改善。

## 视觉与交互检查

- 已人工查看两版本浅色截图及优化后深色截图，柔光配色、卡片和顶栏观感保留，背景位置固定。
- 优化后四块色块计算样式均为 `animation: none`、`will-change: auto`、`filter: blur(64px)`，空闲页面没有运行中的动画。
- CDP 强制标题 `:hover` 后，计算样式为 `brand-shine`、1 次、1.4 秒；等待 1.8 秒后没有运行中的动画。
- 模拟 `prefers-reduced-motion: reduce` 后，标题悬停的动画名称为 `none`。
- 新增渠道弹窗能够打开，未保存业务数据。截图仍可见固定底栏。
- 本机交互检查中顶栏、卡片与弹窗的实际 `backdrop-filter` 计算值为 `none`，原样记录在 JSON；本次没有修改这些规则，也没有将它们单独认定为 CPU 根因。验证结论针对装饰动画整体停用，不区分背景漂浮与文字扫光各自的贡献。

## 工程检查与边界

`pnpm run typecheck`、`pnpm test`（201/201）、优化前后 `pnpm run build:dev`、`git diff --check` 均通过。改动只涉及装饰样式及其参数，不新增业务测试；按实施工作流的低风险样式规则跳过独立三轴评审、复杂度及突变审计。

这是本机短时静置对照，未测滚动、长列表、实时请求、耗电瓦数或长期内存。未更改正式安装版、版本号或发布标签。
