# 布局与易用性改进

2026-10-21。用户要求参考成熟产品、可借鉴 Apple，但保留 Portunus 现有风格。本轮直接调整现有 React 页面，没有引入新 UI 框架、后端接口或真实业务数据。

## 参考与设计取舍

通过 ego-browser 实际阅读 [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Apple Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)，并查看 [Linear 官方产品页](https://linear.app/features)。Apple 的对齐、信息分组、渐进披露和可收起侧栏用于本轮结构设计；Linear 只作字体层次、留白和对比的视觉参考，未声称复制其实际登录应用。保留暖橙主色、蟹形 Logo、明暗主题、柔和背景、圆角与卡片展开动画，降低装饰背景对正文的干扰。

- 桌面壳层：侧栏负责六个模块导航；独立工具栏负责当前位置和收起侧栏；主区域统一内容边距与标题。原顶部导航胶囊及专用动画 hook 删除，避免保留两套导航。
- 资源页面：渠道完整名称和操作分区，搜索在本地执行；模型保持服务端筛选与分页。破坏性操作降权但保留明确入口与确认。
- 额度：卡片只给紧凑状态与分币种金额，多项不合计、超出项有详情入口；配置弹窗加宽，分节表单、内部滚动、固定底部操作与错误提示。
- 日志：常用筛选常驻、高级筛选可展开，已生效条件始终可见；统计口径收进可访问说明。低高度窗口保留表格空间，展开筛选后页面可滚动。
- 分组、服务接入、设置统一表面和条目层级；保留已有查询、复制令牌、局域网配置和更新流程。

## 验证范围与方法

使用本目录 `mock-server.cjs` 在 `127.0.0.1:18767` 提供内存模拟渠道、分组、模型、日志和额度；没有读取/复制 Dev 或正式数据，没有外部上游请求。浏览器只有一个任务空间（29）。截图采用真实1024×576 iframe视口，非大截图缩放；同时检查宽屏。页面切换等待进入动画完成后截图。

测试设计：六路导航及当前选中项；键盘跳转内容不修改 HashRouter 路由；收起/展开侧栏；渠道本地搜索/无结果恢复；编辑/删除确认入口；模型原查询与分页；日志更多筛选应用/清空；长额度表单滚动时底部操作可见；明暗主题、最小窗口与降低动画设置。布局与样式不增加镜像实现测试；新增搜索逻辑有业务边界测试。

实际检查结果：

- 六路页面在1024×576明暗主题均无全局横向溢出，列表/长文在自己的容器滚动；日志宽表保留内部横向滚动。
- 小窗侧栏六项均可见，nav scrollHeight/clientHeight 均415px。收放侧栏保持原路由；键盘“跳转到内容”保持 `#/channels` 并把焦点送到 `workspace-content`。
- 渠道搜索不存在关键字显示0/4及恢复入口，清空后恢复；不发网络查询。原有编辑按钮仍打开包含连接字段的 ExpandEditor，未保存或触发模型调用。
- 日志更多筛选中填写分组并查询，常驻条件标签显示该分组；清空后恢复全部记录。初版表格距顶482px的问题已修复到361px，表格高度至少180px；同时展开高级筛选/口径后页面scrollHeight=710、clientHeight=465，表格保持180px，可完整滚动。结果/详情列提前展示，诊断明细仍可横向查看。
