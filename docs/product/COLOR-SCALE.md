# Portunus 颜色色阶规范

状态：已实施（2026-10-23，`web/src/renderer/index.css`）
主色来源：`web/src/renderer/assets/logo.png`

## 1. 取样与结论

对 1024×1024 的 logo 做像素聚类（忽略透明与纯白背景）后，主体橙色为：

| 取样 | Hex | OKLCH | 说明 |
|---|---|---|---|
| 主体橙 | `#F85820` | `oklch(66.9% 0.205 37.6)` | 品牌主色，占比最高 |
| 暗部红橙 | `#C02010` | `oklch(48.1% 0.178 30.3)` | logo 阴影，不单独作为 token |
| 亮部浅橙 | `#F8C088` | `oklch(83.5% 0.089 62.6)` | 高光，不单独作为 token |

当前主题的 `--accent`：

- 亮色：`oklch(57% 0.20 48)` ≈ `#CE4100`
- 暗色：`oklch(74% 0.15 48)` ≈ `#F68A4F`

两者色相都是 **48**，比 logo 的 **37.6** 偏黄约 10°，实际观感更像“棕橙”。本规范把品牌色相统一到 logo 的 `37.6`，亮度与对比度基本保持现状。

## 2. 分层与命名

只分三层，避免页面直接引用原始色：

1. **Primitive**：`--brand-*`、`--neutral-*`（亮色暖灰）、`--cool-*`（暗色冷灰）、`--success-*`、`--warning-*`、`--danger-*`
2. **Semantic**：`--accent`、`--background`、`--surface`、`--foreground`、`--muted`、`--border`、`--success` 等
3. **Component**：按钮、输入框等只在自身 token 内引用 semantic

品牌色阶 11 档，中性色阶 11 档，状态色每类只保留 4 档（100 浅底 / 400 暗色实心 / 500/600 亮色实心 / 700 文字）。

- 暗色模式实心主操作使用 `brand-400` + `cool-950` 文字（7.78:1）。

## 5. 状态色 Status

品牌橙不再兼任警告色。当前 `--warning` 的色相是 46，与品牌橙几乎同色，容易被当成主操作；规范把警告移到琥珀色相 **80**。

| 角色 | 浅底 100 | 亮色实心（白字） | 亮色文字（浅底上） | 暗色实心（深字） |
|---|---|---|---|---|
| Success | `#D9F4D9` `94% 0.045 145` | `#256C2C` `47% 0.120 145`（6.44:1） | `#256C2C`（5.49:1） | `#5EB663` `70% 0.145 145`（7.50:1） |
| Warning | `#FFEDC3` `96% 0.060 80` | `#845B00` `50% 0.110 80`（6.04:1） | `#845B00`（5.22:1） | `#FFC554` `86% 0.145 80`（12.01:1） |
| Danger | `#FFE4E5` `94% 0.035 15` | `#CB234A` `55% 0.200 15`（5.41:1） | `#B6143F` `50% 0.190 15`（5.53:1） | `#F56B7C` `70% 0.170 15`（6.54:1） |

补充档位：`success-500`（`#3A9742`）和 `warning-500`（`#F0B135`）只用于需要更亮的图标或徽标，**配深色文字**（分别 4.73:1、9.20:1）；不要在这两档上放白字。

状态色必须同时带图标或文案，不能只用颜色表达成功/失败。

## 7. 使用规则

1. **60-30-10**：中性色承担 60%（底色/表面）与 30%（文字/边框），品牌橙不超过 10%（主操作、选中、焦点、图表强调）。
2. **品牌橙不表示状态**：成功、警告、错误一律用状态色；警告与品牌橙的色相至少拉开 40°。
3. **文字对比**：正文与辅助文字 ≥ 4.5:1；大字号可放宽到 3:1。
4. **非文本对比**：焦点环、输入边界、图表线条 ≥ 3:1。
5. **亮橙不配白字**：`brand-500` 上的白色小字只有 3.28:1；要么换成 `brand-600`，要么改用深色文字。
6. **暗色不是反色**：品牌橙在暗色模式提亮到 400，配深色文字；中性色切换为冷灰色相。
7. **不要新增相近橙色**：禁止再引入 `#F97316`、`#FF6B35` 这类近似值；需要深浅时只取本规范档位。
8. **半透明用 color-mix**：状态浅底、选中态优先 `color-mix(in oklch, <color> 15%, transparent)`，不要随手 rgba。
9. **页面代码只引用 semantic token**；只有图表、品牌图形可以直接使用 `--brand-*`。

## 9. 与现状的迁移

以下映射已于 2026-10-23 应用到 `web/src/renderer/index.css`，保留作变更记录。

| 现有 token | 现值 | 建议值 | 原因 |
|---|---|---|---|
| `--accent` 亮 | `oklch(57% 0.20 48)` | `--brand-600` | 色相 48 → 37.6，对齐 logo |
| `--accent` 暗 | `oklch(74% 0.15 48)` | `--brand-400` | 提高饱和，保留暗色深字 |
| `--focus` | 跟随 accent | `--brand-500` / `--brand-400` | 焦点环更亮，与实心按钮分层 |
| `--warning` 亮 | `oklch(50% 0.14 46)` | `--warning-700` | 色相移出品牌橙，避免误认主操作 |
| `--warning` 暗 | `oklch(84% 0.12 50)` | `--warning-400` | 同上 |
| `--success` 亮 | `oklch(47% 0.18 124.48)` | `--success-700` | 统一绿色相 145 |
| `--success` 暗 | `oklch(82% 0.16 124.48)` | `--success-400` | 同上 |
| `--danger` 亮 | `oklch(48% 0.22 25)` | `--danger-600` | 色相 25 → 15，与品牌橙拉开 |
| `--danger` 暗 | `oklch(74% 0.18 25)` | `--danger-400` | 同上 |
| `--muted` 亮 | `oklch(52% 0.015 34.39)` | `--neutral-600` | 数值已经接近 |
| `--muted` 暗 | `oklch(76% 0.015 265)` | `--cool-400` | 保持 5.8:1 的辅助层级 |
| `--border` 亮 | `oklch(90% 0.0088 34.39)` | `--neutral-300` | 数值接近 |
| `--border` 暗 | `oklch(30% 0.02 265)` | `--cool-700` | 数值接近 |

主按钮原先用 `color-mix(in oklch, var(--accent) 88%, white)` 提亮，白字实际只有 3.68:1；已改为直接使用 `--accent` / `--accent-hover` / `--accent-pressed`，玻璃感由内高光与阴影保留。

迁移要求：

- 一次只改一层（先 brand，再 neutral，最后 status），每步做亮/暗截图回归。
- 不新增第三种橙色；组件里出现的硬编码 `#F...`、`rgba(...)` 一并替换为 token。
- 迁移后重新跑对比度检查，至少覆盖：主按钮、辅助文字、表格表头、状态标签、焦点环。
